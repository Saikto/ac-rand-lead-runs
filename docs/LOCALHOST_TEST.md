# Проверка localhost remote leader

Цель текущего теста — проверить библиотеку ранов, server-side playback state machine и управление из resizeable CSP app window. Высота кузова, колёса, звук и односторонний контакт backend-а уже подтверждены. Текущий диагностический проход измеряет, какие данные о колёсах и подвеске CSP восстанавливает у сетевого лидера; дым и следы шин пока не подменяются искусственными эффектами.

## 0. Проверка recorder

После установки через `.\tools\install.ps1` включи app `Random Lead Runs` в Content Manager и запусти New Mode `AC Random Lead Runs — Recorder`.

1. Нажми `Start recording` и проедь несколько секунд.
2. Нажми `Stop recording`.
3. Убедись, что обе кнопки `Keep run` и `Discard run` активны.
4. Нажми `Keep run` и проверь статус `saved` либо `Discard run` и статус `idle`.

Recorder больше не требует opponent car и не содержит старых playback/debug-кнопок.

## 1. Запуск сервера

Открой PowerShell в корне репозитория и выполни:

```powershell
.\tools\start-localhost-test.ps1
```

При первом запуске сборка может занять некоторое время и показать предупреждения об upstream `Scriban`. Для localhost fixture они ожидаемы. Дождись строки:

```text
Server startup completed
```

Окно PowerShell нужно оставить открытым. `Ctrl+C` в нём останавливает сервер.

Launcher автоматически:

- выбирает самый свежий `latest.json` как начальный ран;
- загружает все валидные совместимые `*.json` из той же папки и дедуплицирует `latest.json` по run ID;
- проверяет наличие записанных трассы, layout и машины;
- создаёт player slot 0 и недоступный игрокам leader slot 1;
- запускает сервер с частотой 50 Hz;
- запускает выбранный ран в loop с задержкой 5 секунд.

## 2. Подключение

В Content Manager подключись напрямую к `127.0.0.1:9600`. Если удобнее через invite link, при запущенном сервере открой:

`https://acstuff.club/s/q:race/online/join?ip=127.0.0.1&httpPort=8081`

Сервер уже настроен на машину и layout из текущего рана. После загрузки лидер должен появиться и начать playback через 5 секунд. Между повторами — пауза 3 секунды.

Открой resizeable app window `Random Lead Runs`. В online-сессии оно автоматически подключается к локальному API на `127.0.0.1:8081` и показывает серверный статус.

## 3. Кнопки

- `Play selected run` — перейти в single/current mode и запустить выбранный ран;
- `Play next run` — выбрать следующий ран библиотеки и запустить его;
- `Start random mode` — выбрать равновероятный случайный ран; после каждого loop выбирается заново, immediate repeat разрешён;
- `Restart current attempt` — перезапустить именно текущий выбранный ран;
- `Stop and hide leader` — остановить playback и убрать лидера.

В random mode ID и индекс выбранного рана скрыты до конца попытки. Строка `Last completed` после финиша раскрывает только что завершённый ран.

## 4. Что проверить

Запиши отдельно:

1. Все пять кнопок меняют состояние без hotkeys и без перезапуска сессии.
2. `Stop` действительно скрывает лидера, а следующий запуск возвращает его на старт записи.
3. `Next` циклически обходит библиотеку; при одном ране корректно выбирает его же.
4. Random не показывает выбранный ID до завершения попытки.
5. Между переключениями нет зависшего leader slot или двух лидеров.
6. Playback сохраняет уже подтверждённые visual/audio/collision свойства.

Во время каждого состояния `playing` app автоматически пишет telemetry удалённого leader slot с частотой 10 Hz. В блоке `Visual diagnostics` сравниваются:

- записанная угловая скорость колёс;
- скорость после квантования в сетевой пакет;
- значение, восстановленное CSP у удалённой машины;
- вычисленные CSP `speedDifference`, `slipRatio`, `nSlip` и ход подвески.

Строка `Transport` должна показывать `csp_custom_update`. Это тот же CSP transport, который AssettoServer использует для своих AI cars. `legacy_position_update` означает, что подключённый клиент не объявил поддержку Custom Update.

После одной полной попытки нажми `Copy visual diagnostics` либо просто сообщи, что тест завершён: CSV сохраняется автоматически.

## 5. Добавление ранов

Новые `Keep run` больше не перезаписывают историю: каждый ран сохраняется как `<run-id>.json`, а `latest.json` обновляется как совместимый указатель. Сервер читает библиотеку при запуске, поэтому после записи новых ранов localhost server пока нужно перезапустить.

## 6. Логи

Все логи сохраняются здесь:

```text
N:\_Dev\Code\projects\ac-rand-lead-runs\.runtime\localhost-server\logs
```

После теста можешь просто написать: «посмотри логи localhost server». Для конкретного запуска полезно также прислать приблизительное время теста и наблюдения по пунктам выше.

Диагностические CSV от in-game app сохраняются отдельно:

```text
C:\Users\Igor\Documents\Assetto Corsa\ac-random-lead-runs\logs\remote-visual-*.csv
```

Поэтому после visual-теста достаточно написать: «посмотри remote visual logs».

Сгенерированная конфигурация и сведения о выбранном ране находятся в `.runtime\localhost-server\cfg` и `.runtime\localhost-server\runtime-info.json`.
